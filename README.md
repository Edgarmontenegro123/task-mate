# Task-Mate 📝

Task-Mate es una aplicación de gestión de tareas personal diseñada bajo un enfoque de **productividad minimalista**. Este proyecto fue desarrollado como entrega final académica para la tecnicatura, con el objetivo de ofrecer una interfaz intuitiva, rápida y visualmente agradable para organizar el día a día.

## ✨ Características Principales
- **Gestión Integral:** Crea, edita, tacha y elimina tus tareas con fluidez.
- **Drag & Drop:** Organiza tus prioridades fácilmente arrastrando y soltando tus tareas.
- **Personalización:** Selección de colores para categorizar notas y **Modo Oscuro** para una mejor experiencia visual.
- **Diseño Responsive:** Optimizado para funcionar correctamente en distintos tamaños de pantalla.
- **Persistencia:** Enfocado en mantener tus pendientes siempre accesibles.

## 🛠 Stack Tecnológico
- **Framework:** [Next.js 14](https://nextjs.org/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Drag & Drop:** [react-beautiful-dnd](https://github.com/atlassian/react-beautiful-dnd)
- **Alertas:** [SweetAlert2](https://sweetalert2.github.io/)
- **Iconos:** [FontAwesome](https://fontawesome.com/)

## 🚀 Instalación y Uso
Para ejecutar este proyecto de forma local, asegúrate de tener [Node.js](https://nodejs.org/) instalado y sigue estos pasos en tu terminal:

1. Clona el repositorio: `git clone https://github.com/Edgarmontenegro123/task-mate.git`
2. Ingresa a la carpeta: `cd task-mate`
3. Instala las dependencias: `npm install`
4. Inicia el servidor de desarrollo: `npm run dev`
5. Visualiza el proyecto: Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
